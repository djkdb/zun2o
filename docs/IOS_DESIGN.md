# 실제 아이폰처럼 — iOS 26 디자인 적용 노트

기준은 iOS 26(Liquid Glass)이고, 화면은 390 × 844 아이폰입니다. 수치는 Apple HIG와 iOS 26 리뷰 및 가이드를 참고했습니다.

## 적용한 것

| 부분 | 실제 iOS 26 | 게임에 적용 |
|---|---|---|
| 폰트 | SF Pro + Apple SD Gothic Neo | `-apple-system`을 맨 앞에 둠. 아이폰과 맥에서는 진짜 시스템 폰트로 보이고, 그 밖의 기기는 IBM Plex Sans KR |
| 상태 막대 | 높이 54pt, 시계 17pt semibold, 시계는 섬 왼쪽 공간 가운데 | 3열 그리드로 같은 배치 |
| 다이내믹 아일랜드 | 126 × 37, 위에서 11pt, 하드웨어라 모든 화면 위에 있음 | 모든 오버레이 위에 그림. 실제 노치나 섬이 있는 기기(safe-area-inset-top > 12)에서는 그리지 않음 |
| 백그라운드 통화 | 섬 왼쪽에 초록 수화기와 통화 시간, 오른쪽에 초록 파형 | **01:52부터 끊기지 않은 0200 통화가 섬에 뜸.** 탭하면 통화 화면이 열림. 실제 노치 기기에서는 기존의 초록 시계 알약을 그대로 씀 |
| 배터리 | 숫자가 배터리 아이콘 안에 있고, 20% 이하는 빨강 | 같음. 12%는 처음부터 빨간색 |
| 잠금화면 | 큰 둥근 시계, 반투명 유리 알림, 아래 양쪽 모서리에 손전등과 카메라, "위로 쓸어올려 열기" | 같음. 위로 쓸어 올려도 열림. 손전등 버튼은 켜고 끔. 카메라 버튼은 흔들리기만 하고 **아무것도 열지 않음**(카메라 권한을 묻지 않음) |
| 암호 키패드 | 유리 원 버튼, 숫자 밑에 ABC | 같음. 글자는 CSS로 그려서 버튼 텍스트는 숫자 그대로 |
| 홈 화면 | 둥근 유리 독(아이콘만), 독 위에 '검색' 알약 | 독에 전화·인터넷·메시지·사진. 앱 배치가 뒤섞이는 장면에서는 메모가 독으로 내려오고 사진이 위로 올라감. 01:59에 앱이 사라질 때는 그리드 먼저, 독은 나중에 |
| 앱 열기 | 누른 아이콘 자리에서 앱이 커지며 열림 | 같음. '효과 줄이기'를 켜면 짧은 페이드로 바뀜 |
| 내비게이션 바 | 원형 유리 뒤로가기(꺾쇠만), 가운데 17pt 제목, 첫 화면은 34pt bold 큰 제목 | 같음. 메시지·설정·앨범·녹음·최근 기록에 큰 제목 |
| 메시지 목록 | 파란 안 읽음 점, 이름 줄에 시간과 꺾쇠, 미리보기 2줄, 들여쓴 구분선 | 같음 |
| 대화 화면 | 가운데 프로필 사진과 그 아래 이름 캡슐, iMessage 파랑 #0A84FF와 회색 #262628, 묶음 마지막 말풍선에 꼬리, 내 마지막 메시지 밑에 '읽음' | 같음. **이름 없는 번호는 읽자마자 '읽음 23:52'**, 도현과 엄마는 '전송됨' |
| 입력창 | 왼쪽에 유리 '+' 버튼, 캡슐 입력란, 보내기 화살표는 입력란 안쪽 | 같음 |
| 설정 | 맨 위 계정 카드, 색깔 사각 아이콘, 모서리 26pt 그룹, 꺾쇠 | 같음. 4장부터 계정 이름이 플레이어 이름으로 바뀜 |
| 통화 화면 | 버튼 6개(스피커·FaceTime·소리 끔 / 더 보기·종료·키패드) | 같음. 소리 끔은 버튼 모양만 바뀌고 마이크는 쓰지 않음 |
| 수신 화면 | 잠겨 있으면 "밀어서 응답하기", 풀려 있으면 거절과 응답 버튼 밑에 이름표 | 같음. 잠겨 있을 때도 거절할 수 있게 유리 버튼 '거절'을 둠 |
| 전화 앱 | 떠 있는 유리 탭 막대 | 같음 |
| 알림 배너 | 반투명 유리, 섬 아래로 내려옴 | 같음 |

## 앱 아이콘

Apple 아이콘 원본은 저작물이자 상표 성격의 디자인이고, Apple 디자인 리소스는 Apple 플랫폼용 앱 디자인과 목업에만 쓰게 되어 있습니다. 그래서 그대로 가져다 쓰지 않고, **iOS 26 방식(위에서 내려오는 빛, 유리 테두리, 아이콘 그림자, 22.4% 모서리)으로 직접 그렸습니다.** 보자마자 어떤 앱인지 떠오르게 하되, 모양은 Apple 것을 따라 하지 않았습니다.

| 앱 | 디자인 | 밤이 깊어지면 |
|---|---|---|
| 메시지 | 초록 바탕에 둥근 사각 말풍선(Apple의 타원 말풍선이 아님) | 4장: 말풍선 안에 입력 중 점 세 개 |
| 전화 | 초록 바탕에 수화기 | — |
| 인터넷 | 파랑 바탕에 지구본(나침반이 아님) | — |
| 사진 | 흰 바탕에 겹친 사진 두 장, 앞장은 노을 진 능선(꽃잎이 아님) | 4장: 노을이 잿빛으로 바래고, 능선 위에 아주 작은 사람 하나 |
| 메모 | 노란 스프링 메모장 | 3장: 아무도 쓰지 않은 갈색 낙서 한 줄. 4장: 그 낙서가 빨간색 |
| 녹음 | 빨강 바탕에 흰 파형(Apple의 검은 바탕이 아님) | 3장: 막대 하나만 너무 큼. 4장: 그 소리 하나만 남고 나머지는 평평 |
| 설정 | 회색 바탕에 톱니 | — |
| 출입 기록 | 검정 바탕에 붉은 장부 | — |

## 일부러 적용하지 않은 것

- **말풍선마다 붙은 시간.** 실제 iOS는 왼쪽으로 밀어야 시간이 보이지만, 이 게임은 시간이 단서라서 그대로 둡니다.
- **앱 안 배너 위치.** 실제 iOS 배너는 화면 맨 위에서 뒤로가기 버튼을 가립니다. 이 게임에서는 몇 초 동안 조작을 막지 않도록 내비게이션 바 아래에 띄웁니다.
- **Apple 원본 아이콘과 SF Symbols:** 라이선스 문제로 쓰지 않았습니다(위 "앱 아이콘" 참고).
- **마이크·카메라 사용 표시(주황·초록 점).** 겁을 주는 연출로 쓸 수는 있지만, 실제로 마이크를 켠 것처럼 오해할 수 있어서 넣지 않았습니다. 이 게임은 카메라·마이크·위치를 쓰지 않습니다.
