# UI/UX · 스토리 감사 — 「12%」

기준: “게임 UI를 조작한다”가 아니라 “남의 진짜 폰을 들고 있는데, 그 폰이 나를 알아본다”.
원칙: 정상 90% · 이상 10%. normal → tiny anomaly → normal → suspicious → silence → realization → payoff.
엔진(`script.ts`의 Beat/Action, `director.ts`)과 3개 엔딩·사진/영상 슬롯·세이브 구조는 그대로 둔다.

## 0. 현재 구조 요약 (분석)

| 층 | 파일 | 하는 일 |
|---|---|---|
| 스토리 | `content/script.ts` | `on` 이벤트 → requires/forbids → msg·call·photo·objective·scare… 순차 실행 |
| 콘텐츠 | `threads.ts` `media.ts` `archive.ts` `calls.ts` `replies.ts` | 대화 기록, 사진·메모·녹음, 기록보관소, 통화, 자유 입력 답장 |
| 엔진 | `engine/director.ts` | 비트 실행, 통화/알림 대기(whenFree), 힌트 4단계, 작은 이상 현상(anomaly), 입력 중 떡밥(teaseTyping) |
| 화면 | `phone/*` | 콜드 오픈 → 잠금 → 홈 → 앱 7개 + 출입 기록 → 02:00 → 엔딩 |

이미 있는 “폰이 나를 안다” 장치: 가장 많이 연 앱 아이콘이 2장부터 살짝 비켜남(`habit`), 장별 이상 현상 풀(시계 02:00 깜빡임·입력 중·진동·화면 어두워짐·유령 알림·사진 시각 도장), 대화방에 가만히 있으면 상대가 입력하다 멈춤, 4장 앱 셔플, 재부팅 후 배경화면이 내 사진, 02:00 낭독이 내 행동을 읊음.

## 1. 현재 문제 → 개선 목표

### 1-1. 첫 5분이 “게임 화면”처럼 보인다
- 문제: 홈 화면이 7개 앱 정렬 그리드 + 캘린더 하나. 채원이 쓰던 흔적(개인 일정, 말투, 생활 패턴)이 메모·메시지 안에만 있고 홈에는 없다. 채원의 사진은 전부 폐교 사진이라 “사람”이 보이기 전에 “공포”가 먼저 온다.
- 목표: 홈부터 채원의 폰. 캘린더에 개인 일정(엄마 생신, 편집 마감), 메모에 생활 메모, 엄마 대화에 평범한 일상. 채원은 “사라진 사람”이 아니라 “어제까지 평범했던 사람”.

### 1-2. 이상 현상이 장과 무관하게 무작위
- 문제: anomaly는 확률로 터지고, “홈 화면 자체가 변한다”는 장별 곡선이 약하다.
- 목표 (홈 화면 곡선):
  - 1장: 완전히 정상.
  - 2장: 아주 작은 이상 — 캘린더에 만든 적 없는 일정 “02:00”(제목 없음), 배경 아주 조금 어두워짐, 배터리가 이상하게 그대로(12%).
  - 3장: 폰이 기억함 — 읽은 대화 배지가 잠시 뒤 다시 뜸, 잠깐 다른 앱에 있다 돌아오면 앱 하나가 “열려 있던” 흔적(최근 앱 표시).
  - 4장: 정상 OS가 아님 — 출입 기록 앱이 스스로 생김(있음), 앱 이름이 잠깐 이상하게 보임, 앱 하나가 사라졌다 돌아옴, 시계가 당신 시계와 어긋남(있음).
  - 5장(02:00): 홈은 더 이상 안전지대가 아님 — 앱이 하나씩 사라짐(있음).

### 1-3. 발신자 정보 없음의 “앎”이 대사로만 커진다
- 문제: 상대가 내 이름·시각을 아는 건 대사로 전달되지만, 내가 지금 보고 있는 화면을 아는 순간이 적다.
- 목표: 단계 — ①내가 안 한 일을 안다 ②지금 보는 화면을 안다(사진·브라우저를 연 순간 반응) ③이름 ④사진 속 내용 ⑤내 실제 시간 ⑥앱을 열기 전에 이미 메시지가 와 있음(4장: 열자마자 “방금” 도착).
- UI 패턴: 입력 중… → 사라짐 → 다른 앱 알림 → 메시지 앱으로 돌아오면 없던 메시지.

### 1-4. 설명(exposition)이 직접적이다
- 문제: 규칙(“02:00에 학교 안에 있으면 갇힌다”)을 메모 n2, 채원 문자, 기록 013, 출입 기록 앱, 02:00 낭독이 거의 같은 문장으로 반복.
- 목표: 설명 → 단서 → 연결 → 확신. 각 출처가 규칙의 **일부만** 보여 주고 표현이 겹치지 않게.
  - 메모(채원): 소문 한 줄 (“2시에 거기 있으면 안 된대”).
  - 기사: 박현우 “다음 사람이 왔다”.
  - 출입 기록 앱: 숫자와 상태만 (#0025 풀려남, #0026 안에 있음, #0027 들어옴).
  - 채원 문자: 체험 (“두 시에 다음 사람이 적히면 나는 나갈 수 있대”).
  - 기록 013(서미령): 유일한 전체 설명, 1인칭.
  - 도현: 실천 (“그 폰 꺼요”).

### 1-5. 서미령의 이중성이 늦게 드러난다
- 있는 것: 숨김 앨범 비번을 흘림, “문 열어 뒀어요”, 4장 “…써요”를 보냈다 지움, 엔딩 3 해명.
- 부족: 중반에 “경고”(위험한 곳을 미리 알려 줌), 명령을 거스를 수 없어 지워지는 메시지가 한 번뿐, “왜 계속 이름을 물었는지”의 연결.
- 목표: 위협하면서 돕는다. 2~3장에 경고 1회(“계단은 끝까지 올라가지 마요. 채원 씨는 올라갔어요.”), 3장에 삭제되는 도움 1회, 02:00 낭독에서 “이름을 물은 이유” 한 줄.

### 1-6. 도현은 구조 요청 문자를 보내는 사람에 가깝다
- 목표: 현실적 친구(초반) → 걱정·죄책감(“그날 입구에서 기다리기만 했어요”) → 실제로 들어감 → 자기가 기록될 수 있음을 앎. 전원 끄기 슬라이더를 밀 때 “강도현 — 대기”가 떠올라, 도망치면 누가 남는지 손으로 느끼게.

### 1-7. 02:00이 “텍스트 화면”으로 시작한다
- 문제: 바로 02:00 알림 폭주로 들어가 정적이 없다.
- 목표: 01:59 붕괴 시퀀스 — 배터리 3% · 통신 불안정 · 메시지 지연 · 도현 전화(연결 실패) · 사진 앱이 저절로 열림(“방금” 찍힌 사진) · 홈 · 카메라 사용 중 표시 → 02:00:00 **모든 소리 정지**, 시계 정지 → 폭주 → 영상통화 → 낭독 → 선택.

### 1-8. 엔딩 차별화
- 엔딩 1: 도망쳤지만 다른 사람이 남았다 + “다음 사람”(#0029)의 존재.
- 엔딩 2: 서미령이 31년 한 일을 이어받는다(이름을 적는 사람).
- 엔딩 3: 공포를 거둬 새벽과 정적, 빈 전화부스(영상 있음).

### 1-9. 브라우저
- 목표: “누군가 운영하던 이상한 기록 사이트”. 주소창(자물쇠 없음·“주의 요함”), 탭 제목, 파비콘, 깨진 이미지 1개, 오래된 공지, 죽은 링크(“페이지를 찾을 수 없습니다”), 관리자 메모. 레트로 디자인이 주인공이 되지 않게 절제.

### 1-10. UI 디테일
- 누름 상태(:active) 부족, 앱 전환이 즉시라 “기계” 느낌, 배지 재등장 없음. 정상 화면 90%를 지키며 질감만 추가.

## 3. 스토리 영향
- 규칙·퍼즐 답(0113, 1340, 001→003→007, HAEWON-0200, 서미령) 불변.
- 같은 사실이 여러 출처에 **부분적으로** 흩어져 플레이어가 조립. 기록 013만 전체를 말한다.
- 서미령: 위협(이름·기록) + 도움(비번·경고·지워지는 메시지) 동시 진행 → 엔딩 3 “이름을 불러 줘서”로 수렴.

## 4. UX 영향
- 처음 5분: 정상 폰(개인 흔적) — 이상은 거의 없음.
- 10분: 홈의 작은 어긋남(유령 일정·배터리).
- 15분: “지금 보는 것”에 대한 반응, 배지 재등장.
- 20분: 01:59 붕괴 → 02:00 정적 → 선택.
- 힌트 4단계 유지, 1단계는 계속 인물 문자(세계관 내부).

## 5. 위험 요소
- 이상 현상 과다 → “글리치 게임”: 장별 상한(각 1~3회)과 정상 시간 유지, reduced effects에서 시각 효과 제외.
- 타이밍 충돌(통화·대화 중 이상 현상): 모두 `playerBusy()` 확인.
- 02:00 시퀀스 길이 증가 → “02:00부터 다시”가 길어짐: 붕괴 시퀀스는 9초 이내.
- 자동 QA(`scripts/playtest.mjs`)의 텍스트 의존: 바뀐 문구는 함께 갱신.
- 실제 카메라는 절대 쓰지 않는다: “카메라 사용 중” 표시는 화면상의 점일 뿐.
- 새 사진(채원의 밝은 일상 사진)은 에셋이 없으므로 이번엔 메모·메시지·캘린더로 표현하고, 사진 프롬프트는 `ART_PROMPTS.md`에 추가.
