# 설계 리뷰 — 「12%」 (12라운드)

"스토리, 게임 요소, 공포도가 전체적으로 조금 아쉽다"는 피드백을 외부 공개 스킬의 평가 틀로 다시 잰 기록입니다.
스킬 파일은 저장소에 넣지 않았고, 평가 기준만 가져왔습니다.

방법: 자동 플레이 스크린샷 57장(콜드 오픈 → 엔딩 3종)을 처음 하는 사람 시점으로 한 장씩 보면서, 스크립트(`src/content/script.ts`)와 엔딩 코드에 대조했습니다.
페르소나는 둘입니다. **캐주얼 신규**(3분 안에 판단, 두 줄 넘는 글은 건너뜀)와 **장르 비평가**(Simulacra, Sara Is Missing을 해 본 사람)입니다.

## 1. 플레이 타임라인 (고치기 전)

| 시각 | 하는 일 | 감정 | 판정 |
|---|---|---|---|
| 0:00 | 이어폰 → 시작, 비, 폐교, 전화부스로 뛰어감 | Curious | OK |
| 0:40 | 폰이 켜지고 속보와 "들어오세요." → 집는다 | Engaged | OK |
| 1:00 | 잠금화면 알림에서 비번 추리 (0113) | Focused → 작은 "아하" | OK |
| 2:00 | 발신자 정보 없음과 대화, 선택지 c1 | Engaged | ⚠️ 선택이 결과에 영향 없음 |
| 3:30 | 검은 사진 → 밝기 → **점프스케어 1** → 30분이 사라짐 | Tense → 정점 | OK (가장 강한 장면) |
| 5:00 | 도현 전화 → 녹음 17 (비명) | Tense | OK |

| 8:00 | 숨김 앨범 (1340) → 셀카 → **점프스케어 2** → 시간이 사라짐 | Tense | 🔴 1번과 같은 수법·같은 후속 처리 |
| 10:00 | "나에게" 채원 → 기록보관소 001→003→007 → 013 | Focused | ⚠️ 긴 글이 이어짐 |
| 12:00 | 4장: 01:50–01:59 자동 진행 | Tense → Tense → Tense | 🔴 플레이어가 바꿀 수 있는 게 없음 |
| 14:00 | 02:00: 화면 붕괴 → 영상통화 → **점프스케어 3** → 회상 → 선택 | 정점 | OK |
| 15:00 | 엔딩 3종 | Proud / Cheated | ⚠️ 앞선 선택이 엔딩에 반영되지 않음 |

### 감정 패턴 플래그
- **`Focused → Tense → Tense → Tense` (안전판 없음, HIGH)** — 4장 10분 동안 긴장은 계속 오르는데, 플레이어 손으로 할 일이 없습니다.
- **`Engaged → Neutral` (정체, MEDIUM)** — c1, c2, c3 선택이 회상 문장 한 줄만 바꿉니다. 장르 비평가는 "선택이 가짜"라고 봅니다(Cheated).
- 같은 점프스케어 공식이 반복됩니다. 1번에서 배운 패턴이 2번에서 그대로 재생됩니다(얼굴 lunge → 글리치 → 시간 증발 → 통화 기록 → 메시지). 두 번째부터는 예측이 됩니다.

### 체크포인트
- 0–10초 첫인상 ✅, 10–30초 첫 조작 ✅, 30초–2분 첫 "아하" ✅ (비번)
- 2–5분 실패와 회복 ✅ (비번 3회 오답이면 힌트)
- **5–10분 첫 의미 있는 선택 ❌** — 의미 있는 선택은 02:00에 처음 나옵니다.
- **처음부터 다시 할 이유 ⚠️** — 엔딩 세 개 모두 "02:00부터 다시"로 볼 수 있어서, 처음부터 다시 할 이유가 없습니다.
- **판돈(stake) ⚠️** — "두 시까지 전화부스 문이 안 열린다"는 2장 메시지 한 줄뿐입니다. 플레이어는 자기가 갇혀 있다는 걸 거의 느끼지 못합니다.

## 2. 공포 진단 (horror-weird-fiction 기준)

- **핵심 이상 하나**: 이 게임의 진짜 공포는 귀신 얼굴이 아니라 **"기록이 채원에게서 당신에게로 옮겨 온다"** 입니다. 이미 단계가 흩어져 있습니다.
  1. 잠금화면 "방문해 주셔서 감사합니다. 02:00"
  2. "채원 씨도 1시 13분에 들어왔어요."
  3. "당신 이름은 뭐예요?"
  4. 3층 창문에서 찍힌 *당신* 사진 (p08)
  5. 달력 "02:00 이름 기록 — (당신 이름)"
  6. 녹음 18의 "당신 시계로" 집어 든 시각
  7. 영상 속 당신 뒤의 사람 (v02)
  8. 회상의 "#0027, 당신."

  잘 설계된 사다리인데, 사이사이 점프스케어가 끼어서 흐름이 끊깁니다.
- **클리셰 경고**: 스킬이 첫 번째로 피하라고 하는 "억울하게 죽은 여자" 이미지(긴 머리, 찢어진 입)가 얼굴 lunge로 **세 번** 나옵니다. 세 번째에는 놀라움보다 "또?"가 먼저 옵니다.
- **잘 된 점**: 감정어 대신 감각 묘사를 씁니다("읽은 거 다 보여요", "열 줄 알았어요", 보낸 메시지 취소). 이상 현상이 장마다 커집니다(앱 이름이 바뀌고 아이콘이 사라짐). 스킬이 권하는 방식 그대로입니다.

## 3. 점수표 (build-playability-review, /12)

## 4. 이번 라운드에 바꾼 것

1. **판돈을 1분 안에 체감하게** — 콜드 오픈에서 폰을 집으면 등 뒤에서 전화부스 문이 닫힙니다. [문을 민다]를 누르면 화면이 흔들리고, "꿈쩍도 하지 않는다. 손 안의 화면만 밝다."가 뜹니다. 2장의 "두 시까지는 안 열려요"가 이 장면을 회수합니다. (`ColdOpen.tsx` step 6)
2. **01:55, 진짜 선택 하나** — 도현이 "이번엔 들어갈게요"라고 하면 채원이 "오지 말라고 해. 제발"이라고 하고, 도현 대화에 선택지가 뜹니다.
   - 「들어오지 마요. 밖에 있어요.」 → 도현은 밖에 남습니다. 제2서고에서 오는 전화 대신 누군가 전화부스 유리를 두드리고, 서미령이 "그럼 채원 씨가 계속 여기 있어야 해요. 당신이 대신 오지 않으면."이라고 합니다.
   - 「채원 씨 데리고 나와요.」 또는 14초 동안 무응답 → 도현이 들어갑니다(기존 흐름). 채원이 "왜 안 막았어"라고 합니다.
   - 02:00 회상, 전원 끄기 비용 표시, 「내가 남는다」 설명이 이 선택을 따라갑니다. 세 엔딩 모두에 변형이 있습니다. 도현을 막고 도망치면 **채원이 계속 안에 남는** 새 결말이 나옵니다.
3. **이름을 알려 준 대가** — 이름을 알려 주고 전원을 끄고 도망치면, 엔딩 마지막이 바뀝니다. "그날부터 당신의 휴대폰은 새벽 두 시가 되면 12%에서 멈춘다." + "이름은 적어 뒀어요, ○○ 씨. 들어오세요."
4. **두 번째 점프스케어 → 눈앞에서 바뀌는 사진** — 셀카를 보고 있으면 아무 경고 없이 뒤쪽 서가 사이에 그 여자가 나타납니다. 모든 소리가 멎고, 다음 순간 채원의 볼 옆에 붙어 있으며, 아주 가까이에서 숨소리가 들립니다. 얼굴 lunge는 이제 두 번(검은 사진, 02:00)뿐이고, 사이에 결이 다른 공포가 하나 들어갑니다.
5. **사다리에 단계 하나 추가: 폰 주인이 바뀐다** — 4장(01:50)부터 홈 화면 아래와 설정의 "채원의 휴대폰"이 **"(당신 이름)의 휴대폰"** 으로 바뀝니다. 이름을 안 알려 줬으면 "방문자 #0027의 휴대폰"입니다. 아무도 말해 주지 않고, 글자만 조금 느리게 떠오릅니다.

## 5. 다음 후보 (아직 손대지 않음)

- **마지막 이름이 기억력 테스트** — 기록 003의 목록 제목에 "서미령"이 그대로 있습니다. 목록에서는 가리고, 두세 단서를 엮어야 이름이 나오게 하면 진엔딩에 "아하"가 생깁니다.
- **4장의 할 일** — 선택 하나를 넣었지만, 01:50–01:59에 플레이어가 할 수 있는 행동이 아직 적습니다.
- **정보 밀도** — 1340, 박현우, 카드, 서랍, 외투, 딸까지 고유명사가 많습니다. 캐주얼 신규 기준으로는 규칙 한 줄("두 시에 안에 있는 사람 이름이 적히면 앞사람이 풀려난다")이 더 일찍, 더 분명하게 나와야 합니다.
- **02:00 회상** — 최대 15줄. 개인화된 문장이 가장 강한 부분이라 남기되, 공통 문장을 줄일 수 있습니다.
