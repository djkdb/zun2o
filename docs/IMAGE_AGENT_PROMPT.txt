너는 내 크롬 브라우저를 조작하는 에이전트야. chatgpt.com에서 이미지 5장을 1번부터 5번까지 순서대로 생성하고 다운로드해. 아래 규칙을 정확히 지켜.

[준비물]
- 내 컴퓨터 '다운로드' 폴더에 img-pack 폴더가 있다(압축 해제됨). 그 안에 1~5번 폴더가 있고, 각 폴더에 첨부할 ref 사진이 들어 있다.
- chatgpt.com에 이미 로그인되어 있다.

[이미지 한 장마다 반복할 순서]
1. chatgpt.com에서 "새 채팅"을 연다. 이미지마다 반드시 새 채팅을 연다(앞 이미지가 섞이지 않게).
2. 입력창의 + 버튼(파일 첨부 또는 사진·파일 추가)으로 해당 번호의 첨부 파일을 모두 올린다. 입력창 위에 썸네일이 전부 뜨고 업로드 표시가 사라질 때까지 기다린다.
   - 파일 선택 창을 조작할 수 없으면 거기서 멈추고 "N번 첨부를 직접 해 주세요"라고 말한다. 내가 "첨부했어"라고 하면 3번부터 계속한다.
3. 해당 번호의 '보낼 프롬프트'를 한 글자도 바꾸지 말고 붙여 넣은 뒤 전송한다.
4. 생성을 기다린다. 보통 1~3분, 길면 5분 넘게 걸린다.
   - 20초마다 화면을 확인한다. 기다리는 동안 아무것도 클릭하거나 입력하지 않는다.
   - 다음이 보이면 아직 진행 중이다: "이미지 생성 중", "Creating image", 흐릿하게 차오르는 미리보기, 입력창 오른쪽의 정지(■) 버튼.
   - 선명한 완성 이미지가 보이고 정지 버튼이 사라지면 완료다.
   - 8분이 지나도 끝나지 않으면 페이지를 한 번 새로고침해서 확인한다. 그래도 이미지가 없으면 같은 채팅에 "Please generate the image now." 라고 보내고 다시 4번처럼 기다린다. 이 재시도는 한 번만 한다.
5. 결과를 확인한다.
   - 이미지 대신 질문이 오면(예: "이렇게 진행할까요?"), "Yes, generate it exactly as described." 라고 답하고 4번으로 돌아간다.
   - 이미지 두 장 중 하나를 고르라고 하면 왼쪽(첫 번째)을 고른다.
   - 정책 때문에 거절하면, 프롬프트 맨 앞에 "Calm, non-violent, atmospheric photograph. " 를 붙여 같은 채팅에 한 번만 다시 보낸다. 또 거절하면 그 번호는 건너뛰고 기록한다.
   - 사용량 한도 메시지가 뜨면, 기다리라는 시간이 나와 있으면 그만큼 기다렸다가 그 번호를 1번 단계부터 다시 한다. 시간이 안 나와 있으면 멈추고 나에게 알린다.
6. 다운로드한다. 완성 이미지를 클릭해 크게 연 다음 다운로드(↓) 버튼을 누른다. 다운로드가 시작되었는지 확인한다. 파일 이름을 바꿀 수 있으면 '저장 이름'으로 저장하고, 못 바꾸면 원래 이름을 기록해 둔다.
7. 한 번호당 결과는 한 장만 받는다. 마음에 안 든다는 이유로 다시 생성하지 않는다.
8. 다음 번호로 넘어간다.

[하지 말 것]
- 프롬프트 내용 바꾸기(5번의 거절 재시도는 예외), 결제·플랜 업그레이드·체험판 버튼 누르기, 설정 바꾸기, 다른 사이트로 이동, 이전 대화 삭제, 공유 링크 만들기.
