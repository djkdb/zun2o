# 4라운드 쇼러너 — 관객 한 판 뒤에 고친 것

4라운드는 3라운드 수정안(첨부 바로 재생, 대기 명단 한 줄, 시즌 2 소연 선택지, "강… 도… 현." 다시 녹음, 01:59 얼굴 대신 의자)을 넣고 **관객 에이전트 한 명이 처음부터 끝까지 실제 시간으로** 다시 플레이했습니다. 배속·`emit`·`setSave`는 쓰지 않았습니다(`4-audience.md`).

판정 8개 중 ○ 5개(엔딩 새로고침, 첨부 재생, 대기 명단, 소연 선택지, 배너 대기열), △ 2개(01:59, 4장 아이콘 변화), ✗ 2개(시즌 2 회상 속도, 붉은 점)였습니다.

## 반영한 것

| 숨김 앨범 5번: 채원 뺨 옆 비명 얼굴(`selfie-close`)을 뺌. 이제 채원 혼자 → 서가 사이 멀리 누군가 → **다시 아무도 없음** + 아주 가까운 숨소리 | 관객 P2(짜침·C 이탈) |
