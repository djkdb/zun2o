# 2 · 감독 — 「12%」 연출 보고서

연출 감독으로서 두 시즌을 재생 순서대로 다 읽고 ms 단위로 계산했습니다. 읽은 범위는 다음과 같습니다.

- 콜드 오픈
- `script.ts`, `s2/script.ts`
- 통화, 녹음, 기록, 대화 기록, 답장
- `director.ts`의 액션 실행·이상 현상·반사 연출
- `Overlays.tsx`, `Gallery.tsx`의 스케어
- `Finale.tsx`, `Finale2.tsx`, `Ending.tsx`

`STORY_AUDIT`, `PERSONA_SIM`, `UIUX_STORY_AUDIT`에서 이미 고친 것은 다시 제안하지 않았습니다.

**한 줄 진단.**
- 대사는 많이 좋아졌습니다. 지금 이 게임을 덜 무섭게 만드는 것은 **그녀의 얼굴이 너무 자주 나온다는 것**, 그리고 **4장 2분 반이 같은 높이(8~9)로 붙어 있다는 것** 두 가지입니다.
- 시즌 1에서 그녀의 얼굴이나 몸이 화면에 나오는 순간이 열한 번이고, 그중 일곱 번이 마지막 6분에 몰려 있습니다. 표 아래 「스케어 재고 조사」를 보세요.
- "전화부스 귀신 사진이 짜친다"는 말은 사진 한 장의 문제가 아닙니다. **"당신 뒤에 그녀가 있다"는 같은 그림을 4분 동안 네 번 보여 주는 것**이 문제입니다.

## 2. 연출 수정안

표기: **엔진** 칸의 뜻은 다음과 같습니다.
- `액션` — 기존 Action만으로 됨. `script.ts`만 고침.
- `코드` — 컴포넌트·엔진 코드 몇 줄. 새 Action 타입은 필요 없음.
- `새 액션` — `types.ts`의 Action에 타입 추가가 필요함.

### P0 — 반드시

#### D-01 (P0) 02:00 영상통화: 얼굴 덮치기 → 렌즈가 가려진다
- **위치:** `src/phone/Finale.tsx` `step === 'video'` 효과, 9200ms·10600ms 타이머 / `scare` 오버레이
- **지금:**
  - 6500ms 「잠깐. 네 카메라… 네 뒤에도—」 → 작은 화면(내 카메라)이 미끄러져 들어옴. 그 안에 내 뒤의 그녀가 있음.
  - 9200ms 정면 얼굴 덮치기 + `scream` + 진동 [300,60,600]
  - 10600ms 검은 화면
- **바꿀 것:** 6500ms까지는 그대로. 그다음은 이렇게 바꿉니다.
  - 9200ms: 채원 영상이 그 프레임에서 멈춥니다(`video.pause()`).
    - 자막이 사라지고, `mix(0, 0, 0.08)`로 소리가 0이 됩니다.
    - 통화 시간 표시도 `0:09`에서 멈춥니다.
  - 9200~10600ms: 아무 일도 없습니다. 멈춘 채원의 얼굴과, 작은 화면 속 나와 내 뒤의 그녀만 보입니다.
  - 10600ms: **작은 화면(내 카메라)이 까맣게 됩니다.** 뒤에 있던 무언가가 렌즈를 덮었습니다.
    - `sfx('breath')`, 진동 [30]
    - 소리를 꺼 둔 사람에게는 "소리 인식 · 바로 뒤에서 숨소리가 감지되었습니다."
  - 11800ms: 화면 아래에 「통화가 종료되었습니다」, `sfx('hangup')`
  - 12600ms: `setStep('dark')` → 1800ms 뒤 회상
- **타이밍(ms):** 9200 정지 / 10600 렌즈 가림 / 11800 종료 / 12600 암전. 지금보다 2000ms 길어집니다.
- **엔진:** `코드`(Finale.tsx 타이머 4개, `.video-call .pip-black` 스타일 하나). 새 액션은 필요 없습니다.
- **이유:**
  - 같은 덮치기를 두 번 쓰면 두 번째가 반드시 집니다.
  - "네 뒤에도—"를 들은 사람은 이미 얼굴을 기다리고 있습니다. 기다린 것 대신 **내 카메라가 막히는 것**을 주면, 그녀가 지금 내 바로 뒤에 있다는 게 손에 전해집니다.
  - 음성 32번은 그대로 씁니다.
