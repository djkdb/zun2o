## 1. 총평: 구조에서 가장 큰 약점 세 개

뼈대는 여전히 좋습니다. 괴물이 피해자이고, 플레이어가 찾는 답은 괴물의 이름입니다. "엄마 두 시 전에는 와"라는 약속 한 문장이 두 시즌을 꿰고 있습니다. 그래서 약점은 뼈대가 아니라 **척추 하나가 흩어져 있다는 것**, 그리고 **말이 많다는 것**입니다.

### 약점 1. 이야기의 척추인 "두 목소리"가 장치로만 흩어져 있고, 거둬지지 않는다

시즌 1 발신자 대화방에는 목소리가 둘 있습니다. 하나는 서미령, 하나는 그녀 귀에 규칙을 읽어 주는 것(기록)입니다. 이게 「12%」에서 가장 좋은 발상입니다. 그런데 지금은 단서만 놓여 있고 회수가 하나뿐입니다(엔딩 3 "그때 쓰지 말라고 한 거 / 제 말 아니었어요").

| 놓인 것 | 위치 | 지금 상태 |
|---|---|---|
| 제보 메일 마지막 줄 "폰은 꺼 두세요." ← 왜?? | 메모 n2, 도현 통화, `c2-done` 도현 문자 | 채원이 직접 "왜??"라고 적어 둔 질문인데 답이 없음 |
| "거기 앉아 있던 건 제가 아니에요." | `sees-gallery` | 그럼 누가 앉아 있었나? 두 시즌 어디에도 답이 없음 |
| "여기 묶이면 자기 이름은 입 밖으로 안 나옵니다." | 기록 013, 자유 답장 `askname` | **엔딩 2가 이 규칙을 깸.** 새로 기록자가 된 플레이어가 "저는 {name}이에요"라고 자기 이름을 말함 |

엔딩 2의 모순이 가장 심각합니다. 게임의 주제문("제 이름 물어본 사람은 없었어요")을 마지막 장면이 스스로 배신합니다.

### 약점 2. 발신자가 너무 많이, 너무 친절하게 말한다

시즌 1 장면 스크립트에서 `th: 'unknown'`은 73번 나옵니다. 앱을 열 때마다 반응하고, 장치를 해설하고, 퍼즐 규칙을 대신 설명합니다. 제작자가 말한 "과한 것, 설명하는 것"이 대부분 이 대화방에 몰려 있습니다. 예를 들면 이런 줄들입니다.

- "직접 알아내서 들어와야 하거든요." 게임 디자이너가 하는 말입니다.
- "녹음에서 앉으라고 했죠. 그쪽한테 한 말이에요." 논리도 이상하고(녹음 속 상대는 어젯밤의 채원) 해설입니다.
- "메모 보고 있네요." 다음 줄 하나만으로도 무서운데 앞에서 미리 말해 버립니다.
- "두 시예요. 이름을 적을 시간이에요."
- "이게 더 잘 어울려요."
- "마음 바뀔걸요."

악당 대사 클리셰입니다. 기준을 하나로 정하면 고칠 곳이 바로 보입니다. **그녀는 보고 있다고 말하지 않는다. 본 사람만 알 수 있는 것을 말한다.**

### 약점 3. 시즌 2의 결정은 사람이 아니라 관리자 폼 앞에서 내려진다

시즌 2의 핵심 대가는 "사본을 지우면 엄마도 지워진다"입니다. 그런데 이 결정은 관리 앱에 문장을 입력하는 일로 끝납니다. 엄마가 그 결정에 목소리를 내는 건 **삭제를 예약한 플레이어에게만** 해당합니다(`s2-mom-knows`, `s2-mom-knows-late`). 예약하지 않은 플레이어는 엄마가 01:51에 사이트를 찾아낸 뒤 아무 말도 듣지 못합니다. 감정의 정점이 갈림길 한쪽에만 있습니다.

같은 이유로 시즌 2의 "열린 문"도 비어 있습니다. 시즌 1 플레이어는 갇혀서 남습니다. 시즌 2 플레이어는 나갈 수 있는데도 남습니다. 거울로서는 최고의 차이인데, 이 차이에 의미를 주는 문장이 콜드 오픈과 잠금 화면 방치 대사(`s2-lock-idle2`) 둘뿐이고 엔딩은 이를 거두지 않습니다. 엔딩 4는 날짜 순서까지 뒤집혀 있습니다(10월 28일 다음에 10월 2일).

## 2. 구조 개편안 (장면 추가·이동·압축)

### 2-1. 엔딩 2의 새 기록자는 자기 이름을 말하지 못한다 — **P0**
- **위치:** `src/phone/Ending.tsx` `ENDINGS.shift.scene` 마지막 줄
- **지금:**
  ```ts
  { who: '발신자 정보 없음', text: '들어오세요. 저는 {name}{이에요}. 오래 기다렸어요.', side: 'left' },
  ```
- **바꿀 것:** 말풍선 세 개로 나눕니다.
  ```ts
  { who: '발신자 정보 없음', text: '들어오세요.', side: 'left' },
  { who: '발신자 정보 없음', text: '저는', side: 'left' },
  { who: '발신자 정보 없음', text: '…이상하네요. 분명히 아는데, 안 나와요.', side: 'left' },
  ```
  같은 파일 `endingFor`의 1340 줄 삽입 위치도 함께 고칩니다. 지금은 `scene.length - (id === 'shift' ? 2 : 1)`입니다. 이렇게 바꿉니다.
  ```ts
  const at = id === 'shift' ? scene.findIndex((l) => l.text.startsWith('1년 뒤')) : scene.length - 1;
  scene.splice(at, 0, { text: radio });
  ```
- **이유:** 기록 013의 "여기 묶이면 자기 이름은 입 밖으로 안 나옵니다"와 맞습니다. 플레이어의 이름은 바로 위 해설("이름을 적는 사람 — {name}")에 보이는데 본인은 말하지 못합니다. 이제 플레이어가 서미령의 자리, 즉 "누가 물어봐 줘야 하는 사람"이 됩니다. 이름을 주지 않은 사람에게 "저는 #0027이에요"가 나오던 어색함도 함께 사라집니다.

### 2-2. 첫 1분에 "이름"과 "번호"를 심는다: 잠금 화면의 영수증 — **P0**
- **위치:** `src/content/threads.ts` `INITIAL_THREADS.unknown`
- **지금:** `m('them', '02:00', '방문해 주셔서 감사합니다.', D27)`

- **이유:** 23:51 잠금 화면에서 모두가 이 알림을 봅니다. 어젯밤 02:00, 채원의 이름, 번호 체계가 설명 없이 한 줄에 다 들어 있습니다. 이 대화방의 첫 말이 시스템 영수증 말투이고 그 뒤가 사람 말투라는 점도 "두 목소리"의 첫 단서가 됩니다. 02:00 회상의 "#0025 박현우. #0026 윤채원. 그리고 #0027, 그쪽."이 이 첫 줄과 짝을 이룹니다.

### 2-3. 경고의 주인을 밝힌다: 엔딩 3에 두 줄 — **P0**

- **바꿀 것:** 사이에 두 줄을 넣습니다.

### 2-4. c3에 대답이 생긴다: 채원이 "사람"으로 반응한다 — **P1**
- **위치:** `src/content/script.ts` 베이트 `c3` (`on: 'choice:c3:*'`)
- **지금:** 두 선택지 모두 바로 "도와줘 제발"로 시작합니다. 선택은 02:00 회상의 한 줄만 바꿉니다.
- **바꿀 것:** 갈래 베이트 두 개를 추가하고, 기존 `c3`의 `on`을 `'c3:done'`으로 바꿉니다. `c3` 안의 동작은 그대로 둡니다.
  ```ts
  {
    id: 'c3-chaewon',
    on: 'choice:c3:chaewon',
    actions: [
      { t: 'msg', th: 'self', from: 'me', text: '응 나야', typing: 600 },
      { t: 'msg', th: 'self', from: 'me', text: '여기서 누가 내 이름 부른 거 처음이야', typing: 1500 },
      { t: 'wait', ms: 1200 },
      { t: 'emit', ev: 'c3:done' },
    ],
  },
  {
    id: 'c3-finder',
    on: 'choice:c3:finder',
    actions: [
      { t: 'msg', th: 'self', from: 'me', text: '전화부스에서?', typing: 700 },
      { t: 'msg', th: 'self', from: 'me', text: '…나도 거기서 주웠는데', typing: 1400 },
      { t: 'wait', ms: 1200 },
      { t: 'emit', ev: 'c3:done' },
    ],
  },
  ```
  `c3` 베이트는 `{ id: 'c3', on: 'c3:done', actions: [ …지금 그대로… ] }`가 됩니다.
- **이유:** "이름을 불러 준다"는 주제가 엔딩 3보다 먼저, 채원의 입에서 한 번 울립니다. 02:00 회상의 "채원 씨 이름을 먼저 불러 줬죠. 그 애가 울었어요."도 근거가 생깁니다. "나도 거기서 주웠는데"는 박현우 폰 → 채원 폰 → 나로 이어지는 사슬을 설명 없이 깨닫게 합니다.

### 2-5. 엔딩 1: "끄라고 한 건 도현이었다" — **P1**
