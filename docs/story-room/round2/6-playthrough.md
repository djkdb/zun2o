# 6. 실제 플레이 기록 — 2라운드 (A: 공포 실황 보는 20대 / C: 공포 잘 못 보는 사람)

## 0. 먼저 알아 둘 것

- **이번에 플레이한 빌드는 2라운드의 마지막 수정이 빠진 빌드입니다.** :4173 미리보기의 `dist/assets/index-C1kNkHpV.js`는 16:26:38에 빌드됐습니다. 이건 커밋 `7f473f9`(16:26:01)까지 들어간 빌드이고, 편집자 수정 커밋 `c935c10`(16:38)은 들어 있지 않습니다. 빌드에 없는 것: `ch4-unsay-seen`(대화를 보고 있을 때 "…써요" 지우기), 기록 013 목표 문구 "기록 013을 끝까지 읽자", "잘 나왔네요"(빌드에는 아직 "잘 나왔잖아요"), `lock-idle2`의 `hint-sent` 조건, S2 `s2:named-same` 분기, 엔딩 대사 두 줄. 지시대로 다시 빌드하지 않았습니다. 대신 현재 소스를 `vite` 개발 서버(:5179, `dist`에 손대지 않음)로 띄워 보려 했는데 개발 모드에서 화면이 하얗게 멈춰서 못 했습니다(버그 B10). 개발 서버는 확인 직후 껐습니다.
- 환경: playwright-core가 띄운 크로미움(따로 띄움, 9222 포트는 건드리지 않음), 390×844, `isMobile`·`hasTouch` 켬, 터치 탭과 CDP 터치 스와이프로 조작. 스크린샷은 `qa-output/story-room/play2/`에 있습니다. 1초 간격으로 찍힌 중복 스크린샷은 정리했습니다. 시작 화면 스크린샷 `001-start`는 정리하다 실수로 지웠습니다.
- 공정성 메모: 브리프에 정답 몇 개(0113, 0314, 서미령, 삭제 코드)가 적혀 있어서 완전히 모르는 상태는 아니었습니다. 그래도 매번 게임 안 단서(카메라 알림 01:13, 메모 "그 방송 주파수", "미령 샘", 기록 013 표지 번호)를 보고 나서 입력했습니다. `scripts/playtest*.mjs`는 열지 않았습니다. 힌트 시트("? 막혔나요")도 쓰지 않았습니다.
- 디버그를 쓴 곳(전부 확인용, 1회차가 끝난 뒤):
  - S1 엔딩 뒤 "02:00부터 다시"로 영상통화를 다시 봄. 이건 일반 기능입니다.
  - S2 2회차에서 `setSpeed(4)`. 같은 회차에 `setSave({liveNote:""})`와 `emit("ch4")`로 4장으로 건너뛰어 빈 메모를 확인.
  - S1 2회차에서 `setSave(flags+found-key,self-contact)`와 `emit("ch4")`로 "…써요"를 확인.
  - 관리자 페이지의 방명록 버튼을 `scrollIntoView`로 화면에 끌어옴. 스크롤과 같은 효과입니다.
- 실제로 걸린 시간: 시즌 1은 약 27분(16:33→17:00, 진엔딩), 시즌 2는 약 18분(17:03→17:21, 엔딩 5 「대신」).
- 콘솔 오류: :4173 빌드는 플레이 내내 error와 pageerror가 0건이었습니다. 개발 서버에서만 `Cannot access 'ASKS_NAME' before initialization`이 났습니다.

표기: 시각은 게임 속 시계 기준입니다. 강도는 `A/C`로, 각각 0~5입니다.
