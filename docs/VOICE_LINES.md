# 음성 대사 목록

`npm run voices:list`가 만든 파일입니다. 대사를 바꾸면 다시 실행하세요.

한 줄에 파일 하나: `voice-raw/<번호>.mp3` (wav·m4a도 됨)로 저장하고 `npm run voices:fx`를 실행하면
통화 음질·녹음실 울림·서미령 목소리 처리를 입혀 `src/assets/voice`에 넣습니다.
