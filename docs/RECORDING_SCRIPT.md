# 녹음 대본 (사람 연기 → 목소리 변환)

`npm run voices:script`가 만듭니다. 번호는 docs/VOICE_LINES.md와 같습니다.

**사람이 연기할 줄 31개** — 울음·공황·겁에 질린 속삭임, 그리고 도현·채원·소연의 모든 대사. 나머지 24줄(서미령·엄마의 차분한 대사)은 TTS로 둡니다. 차분하고 단조로운 귀신 목소리는 TTS가 오히려 잘 맞습니다.

## 녹음하는 법
- 조용하고 울리지 않는 방(옷장 앞, 이불 속도 좋음). 폰 음성 메모 앱, 입에서 한 뼘.
- **한 줄을 2~3번씩**, 줄 앞에 번호를 말하고("삼십삼 번") 2초 쉬고 대사. 한 파일에 여러 줄을 넣어도 됩니다. 제가 받아쓰기로 번호를 찾아 자릅니다.
- 성별·나이는 신경 쓰지 마세요. 음색은 변환이 바꿉니다. 바뀌지 않는 건 **숨, 떨림, 멈춤, 감정**입니다. 그것만 진짜로.
- 도현(20대 남자) 줄은 남자가 녹음하면 변환이 더 자연스럽습니다.
- 원본 녹음은 저장소에 올리지 않습니다(voice-raw는 커밋 제외). 변환된 소리만 게임에 들어가고, 게임은 여전히 마이크를 쓰지 않습니다.
