# 출시 점검표

## 이번 출시에 들어간 것

- **iOS 26 화면:** 다이내믹 아일랜드는 PC 프레임에서만 그립니다. 그 밖에 글래스 독, 큰 제목, 6버튼 통화 화면, 직접 그린 앱 아이콘(밤이 깊어질수록 변함)이 들어갔습니다.
- **선명한 배경화면:** 시즌 1 잠금·홈 화면, 재부팅 뒤 배경, 시즌 2 배경을 단일 이미지로 바꿨습니다. 시즌 2에는 1년 뒤의 부스 사진과 01:52 부엌 영상이 추가됐습니다.
- **대사 다듬기:** '발신자 정보 없음'이 메시지를 보내는 순서와 말투, 잠금 해제 직후의 대사, 메모를 볼 때의 대사를 고쳤습니다.
- **안정성:**
  - 화면이 멈추면 빈 화면 대신 "다시 켜기"를 보여 줍니다. 진행 기록은 그대로 남습니다.
  - 설정 화면이 이제 스크롤됩니다.
  - 휴대폰에서 노치가 화면을 가리던 문제를 고쳤습니다.
- **공유 미리보기:** 카카오톡이나 X 등에 링크를 붙이면 제목, 설명, 1200×630 이미지가 뜹니다(`public/og.jpg`).
- **첫 로딩:** 처음 열 때 받는 용량을 10.8MB에서 5.5MB로 줄였습니다. 영상은 처음 재생할 때 받아서 저장합니다.
- **출처 표기:** 설정 화면 → 만든 것.

## 배포

Cloudflare Pages에 연결해 둔 브랜치에 푸시하면 자동으로 빌드됩니다. 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다. 수동으로 배포하려면 `npm run deploy:cf`를 실행합니다.

배포한 뒤 확인할 것:

1. 휴대폰 사파리와 크롬에서 처음부터 잠금 해제까지 해 봅니다. 노치와 통화 화면, 설정 스크롤도 확인합니다.
2. 카카오톡에 링크를 붙여 미리보기 이미지가 뜨는지 봅니다. 예전 미리보기가 남아 있으면 카카오 개발자 도구의 '공유 디버거'에서 캐시를 지웁니다.
3. '홈 화면에 추가'로 설치한 앱에서 오프라인으로 시작해 봅니다. 영상은 한 번 재생한 것만 오프라인에서 나옵니다.

## 남은 일

- **음성:** 타입캐스트 목소리(제찬, 민지, 미소, 정숙)로 교체할 예정입니다. 웹 에디터에서 받은 mp3 한 파일을 `npm run voices:split -- 파일.mp3`로 자른 뒤 `npm run voices:fx`를 실행합니다. 교체하면 설정 → 만든 것에 "Typecast"를 추가합니다. 무료 플랜으로 만든 음성은 상업적으로 쓸 수 없고 출처를 밝혀야 합니다.
- 상업적으로 배포할 생각이면 음성(ElevenLabs·타입캐스트)과 이미지를 만든 서비스의 라이선스를 다시 확인해야 합니다.
