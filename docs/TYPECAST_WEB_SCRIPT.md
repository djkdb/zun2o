# 타입캐스트 웹 에디터 대본 — 한 번에 붙여 넣기

**가장 쉬운 방법:** 웹의 「대본 가져오기 → 텍스트 붙여넣기」에 `docs/TYPECAST_IMPORT.txt`를 통째로 붙여 넣습니다. `화자: 대사` 형식이고 화자 이름이 타입캐스트 보이스 이름(제찬, 민지, 미소, 정숙)이라 보이스가 자동으로 배정됩니다. 55줄이 대사 번호 순서대로 들어가니, 다운로드한 파일 하나를 `npm run voices:split -- 파일.mp3`로 자르면 됩니다.

아래는 캐릭터별로 따로 만들 때 쓰는 방법입니다.

캐릭터마다 프로젝트를 하나씩, 모두 4개 만듭니다. 각 프로젝트에는 아래 블록을 **통째로 한 번에** 붙여 넣으면 됩니다. 한 줄이 한 문장 블록이 됩니다.

1. 새 프로젝트를 만들고 캐릭터를 하나만 고릅니다(제찬, 민지, 미소, 정숙).
2. 해당 블록을 통째로 붙여 넣습니다.
3. 감정은 **스마트 감정(자동)**으로 둡니다. SSFM 3.0이 앞뒤 문장을 보고 감정을 정합니다. 어색한 줄만 골라 감정을 바꿔 다시 생성하면 됩니다.
4. **전체 다운로드(mp3)**를 받습니다. 파일 이름은 아무거나 괜찮고, 이 대화에 4개를 올려 주세요.

줄 사이에 쉼이 짧으면 문장 사이 간격을 0.8초 이상으로 늘려 주세요. 제가 쉬는 구간으로 자르고, 받아쓰기로 확인한 뒤 순서대로 맞춰 넣습니다.
