# 타입캐스트 웹 에디터 대본

## 만드는 법

1. 새 프로젝트 하나에 아래 순서대로 한 줄씩 붙여 넣고, 줄마다 캐릭터와 감정을 지정합니다. 캐릭터: 도현=**제찬**, 채원=**민지**, 서미령·엄마=**미소**, 소연=**정숙**.
2. **줄 사이에 1초 쉼**을 넣습니다. 제가 이 쉼을 기준으로 줄별로 자릅니다.
3. 들어 보고 어색한 줄은 감정이나 강도를 바꿔 다시 생성합니다. 지시는 추천일 뿐입니다.
4. 전체를 mp3 한 파일로 다운로드해 이 대화에 올려 주세요. 제가 받아쓰기로 줄을 찾아 자르고, 장면 효과를 입혀 넣습니다.
