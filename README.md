# 새벽 2시의 휴대폰

> 폐교된 해원고등학교 정문 앞 공중전화 부스. 선반 위에 휴대폰 한 대가 놓여 있다. 배터리 12%.

**주운 휴대폰 호러 게임**입니다 (Simulacra, Sara Is Missing 계열). 화면 전체가 실종된 폐건물 유튜버 **윤채원**의 휴대폰입니다.
잠금을 풀고, 메시지·사진·녹음·통화·브라우저를 뒤져 그날 밤 무슨 일이 있었는지 알아내세요.
정체를 알 수 없는 **발신자 정보 없음**이 실시간으로 말을 걸고, 폰 속 시계는 새벽 2시를 향해 갑니다.

- 플레이 시간 15–20분 · 챕터 5개 · 엔딩 3개 · 이어폰 권장
- **실제 시간과 상관없이 언제든** 플레이할 수 있습니다. (진짜 새벽 2시에 끝까지 가면 대사 한 줄이 더 나옵니다)
- 휴대폰에서 **“홈 화면에 추가”** 하면 앱처럼 전체 화면으로 설치됩니다 (PWA, 오프라인 동작).
- 외부 음원 없음: 소리는 Web Audio로 합성, 목소리는 브라우저 음성 합성 + 자막. 사진은 제작자가 생성한 데모 이미지(없으면 SVG 그림). “그녀”의 목소리는 음절마다 합성한 숨소리를 입힙니다.

## 게임 흐름 (스포일러 약간)

| 챕터 | 폰 시계 | 내용 |
|---|---|---|
| 0 잠금 | 23:51 | 잠금 화면 알림(도현의 규칙 + 카메라 알림)에서 암호를 찾는다 |
| 1 채원의 폰 | 23:52 | “발신자 정보 없음”이 말을 건다 → 마지막 사진을 밝게 보정하면… · 채원도 **이 부스에서 폰을 주웠다** |
| 2 목소리 | 00:47 | 도현의 전화 → 채원의 마지막 녹음 → “당신 이름은 뭐예요?” · 도현이 학교로 출발 |
| 3 제2서고 | 01:12 | 숨김 앨범 → 셀카 → 사라진 시간 동안 **누가 엄마에게 전화를 걸었다** → 채원이 “다음은 너야” → 부스 유리 노크 → **폰이 스스로 재부팅, 배경화면이 당신 사진** |
| 4 두 시 전 | 01:50 | 도현이 부스 뒤의 누군가를 찍어 보내고, 채원을 보고 **건물 안으로 들어간다** → 도현 목소리의 전화 |
| 5 02:00 | 02:00 | 시계 정지, 알림 폭주, 영상 통화, 낭독(“#0025 박현우. #0026 윤채원. 그리고 #0027, 당신.”), 선택 |

**이야기의 규칙** (스포일러): 새벽 2시에 학교 안에 있는 사람 한 명의 이름이 도서관 출입 기록에 남고, 그 사람은 다음 사람이 기록될 때까지 도서관을 나갈 수 없다. 정문 부스의 폰을 주운 사람도 들어온 것으로 보고, 폰이 꺼지면 나간 것으로 본다. 처음 갇힌 서미령만은 풀려나지 못하고 그 뒤로 이름을 적는 존재가 됐다. 기록에 묶인 그녀는 겉으로는 코드를 막지만, 문을 열어 두고 비밀번호를 흘리며 몰래 돕는다(4장에서 “…써요. 두 시에.”를 보냈다가 지운다). 자기 이름은 스스로 말할 수 없어서, 누군가 대신 불러 줘야 한다.
전원을 끄고 도망치면 그 자리는 **안에 남아 있던 도현**에게 간다. 내가 남으면 채원과 도현이 풀려나고, 1년 뒤 다음 사람에게 “들어오세요”를 보내는 건 당신이다. 삭제 코드와 처음 갇힌 사람의 이름으로 기록을 지우면 부스의 선반이 비게 된다.

채팅에는 언제든 답장을 쓸 수 있고 02:00과 채원은 대답합니다. 메시지에 붙은 **사진·녹음·링크 카드**를 누르면 그 자리로 바로 갑니다.

공포 연출은 전부 **플레이어의 행동이 방아쇠**입니다: 사진 밝기를 직접 올리거나, 셀카를 넘기거나, 녹음을 끝까지 듣거나.
그 사이사이에는 어두운 홈 화면에 얼굴이 비치는 순간, 아무도 적지 않은 일정이 캘린더 위젯에 생기는 순간 같은 작은 이상현상이 끼어 있습니다.
막히면 힌트가 네 단계로 옵니다: ① 등장인물의 문자(75초) → ② 살펴볼 앱이 홈 화면에서 은은하게 빛남(130초) → ③ 오른쪽 위 **`? 막혔나요`** — 지금 할 일과 살펴볼 곳(180초) → ④ “더 자세히 알려 줘요”를 눌렀을 때만 직접적인 힌트.
사진은 **두 번 탭하면 확대**됩니다. 작게 찍힌 것을 놓치지 마세요.

## 실사 이미지 넣기 (선택)

현재 `src/assets/art/`에 **데모용 실사 이미지 12장**(제작자가 이미지 생성 도구로 만든 것)이 들어 있어 사진·점프스케어·영상통화·잠금 화면이 사진으로 나옵니다. 파일을 지우면 그 장면은 SVG 그림으로 돌아갑니다. 교체하려면 같은 이름으로 덮어쓰고 빌드하세요. 슬롯 목록과 프롬프트는 [`ART_PROMPTS.md`](ART_PROMPTS.md).

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/ (타입체크 + 빌드 + PWA 서비스워커)
npm run preview      # http://localhost:4173
npm run lint
npm run typecheck
npm test             # 스토리 데이터·대화 엔진·연출 타이밍 테스트 (Vitest)
npm run qa           # 자동 플레이 봇: 처음부터 세 엔딩까지 + 회귀 테스트 (preview 서버 필요)
npm run qa:layout    # 모바일 레이아웃 점검: 390×844 / 360×640(reduced motion) / 320×568 / 430×932 + 가로
```

### 배포

정적 사이트라 어디든 올라갑니다 (`base: './'`).
- **Cloudflare**: Workers & Pages → Create → Pages → Connect to Git → Build `npm run build`, Output `dist` (Node 22는 `.nvmrc`로 고정). 또는 `npx wrangler login && npm run deploy:cf`.
- **GitHub Pages**: `.github/workflows/deploy.yml` 포함 (Settings → Pages → Source: GitHub Actions).

## 디버그 / 촬영

`?debug=1` → 왼쪽 가장자리 **DBG** 버튼: 챕터 점프(CH1–CH4, 02:00), ×6 빨리감기, 새 게임, 귀신 모습별 스케어 미리보기, 작은 이상현상 실행(clock·typing·dim·phantom·stamp·buzz), 엔딩 바로 보기, 시각 +10분, 배터리 5%, 체크포인트 삭제, 사운드 테스트, 이벤트 emit, 채팅 키워드 테스트.
출시 빌드에서 디버그를 완전히 없애려면 `VITE_DISABLE_DEBUG=1 npm run build`.
`?debug=1&speed=4` 는 대화·대기 시간을 4배 빠르게 합니다 (점프스케어·연출 길이는 그대로).

릴스용 추천 장면: 잠금 화면 알림(0:10) · 사진 밝기 올리기 점프스케어 · 도현의 전화 마지막 “끄지 마세요” · 셀카 점프스케어 · 02:00 영상 통화.

## 구조

```
src/
  engine/     types, state(저장+런타임), director(비트 실행기), storage
  content/    script.ts(스토리 전체가 데이터), threads, media(사진·메모·녹음), calls, archive(폰 속 브라우저)
  phone/      PhoneShell, LockScreen, HomeScreen, CalendarWidget, Overlays(알림·통화·챕터·점프스케어·힌트), Finale, Ending, ColdOpen
  phone/apps/ Messages, Gallery, Notes, Memos, Browser, PhoneApp, Settings, IndexApp
  art/        Ghost(그녀), scenes(건물·열람실·평면도…), phonePhotos(폰 카메라 사진·영상 통화)
  audio/      engine(합성 효과음·벨소리·심장박동), speech(음성 합성)
scripts/      playtest.mjs(자동 플레이 봇), icons.mjs(PWA 아이콘 생성)
```

스토리 수정은 `src/content/script.ts`만 고치면 됩니다. 비트 하나는 `이벤트 → 액션 목록`입니다:

```ts
{ id: 'memo-end', on: 'memo:m1:end', actions: [
  { t: 'msg', th: 'unknown', text: '당신 이름은 뭐예요?', typing: 1800 },
  { t: 'choice', th: 'unknown', id: 'c2', options: [{ id: 'name', label: '이름을 알려 준다', input: 'name' }, …] },
]}
```

진행 상황은 브라우저 localStorage에만 저장되고, 대화 도중 새로고침해도 이어서 진행됩니다.

## 개인정보 · 접근성

- 이름과 진행 기록은 **이 기기에만** 저장되며 어디로도 전송되지 않습니다. 카메라·마이크·위치를 사용하지 않습니다. 전화 앱은 가짜이며 실제 전화를 걸지 않습니다.
- 설정 앱 → **효과 줄이기**: 번쩍임·진동·흔들림 없이 순한 버전으로 진행. `prefers-reduced-motion`도 존중합니다.
- 소리를 꺼도 자막으로 전부 진행할 수 있습니다.
