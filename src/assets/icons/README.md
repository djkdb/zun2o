# 앱 아이콘 이미지 (선택)

여기에 앱 이름으로 이미지를 넣으면 그 앱은 직접 그린 아이콘 대신 이 이미지를 씁니다. 없으면 그린 아이콘이 그대로 나옵니다.

| 파일 이름 | 앱 |
|---|---|
| `messages.png` | 메시지 |
| `phone.png` | 전화 |
| `browser.png` | 인터넷 |
| `gallery.png` | 사진 |
| `notes.png` | 메모 |
| `memos.png` | 녹음 |
| `settings.png` | 설정 |

- 정사각형, 180×180 이상. 모서리는 게임이 iOS 비율로 자릅니다(원본은 각진 정사각형이 가장 좋음).
- `png`·`webp`·`jpg`·`svg` 모두 됩니다.
- 이미지로 바꾼 앱은 밤이 깊어질 때 아이콘이 변하는 연출(4장의 입력 중 점, 회색 꽃잎, 돌아가는 나침반 바늘 등)이 빠집니다.
- 넣는 이미지의 사용 권리는 넣는 사람이 확인해야 합니다. 애플 기본 앱 아이콘은 애플의 저작물·상표라서, 공개 배포하면 신고로 내려갈 수 있습니다.
